# cookbook 索引

操作指南层（层级职责见 [AGENTS.md](../AGENTS.md)）：每篇是带编号步骤与可执行「验证」清单的 how-to，只写现在成立的流程——动笔前须对着源码把流程走一遍，设计理由链接 [spec.md](../spec.md) 日期段。

| 指南 | 做什么 |
|---|---|
| [adding-a-tool.md](adding-a-tool.md) | 新增或扩展一个内置工具，并让它通过目录、权限面与提示词快照的全部守卫 |
| [adding-a-section.md](adding-a-section.md) | 新增一个按请求能力动态注入的提示词 section |
| [adding-a-preset.md](adding-a-preset.md) | 演进预设（AgentPreset）：类型、校验规则与设置页接线 |
| [adding-a-skill.md](adding-a-skill.md) | 新增内置 / 工作区 / 全局技能，理解发现顺序与同名遮蔽 |

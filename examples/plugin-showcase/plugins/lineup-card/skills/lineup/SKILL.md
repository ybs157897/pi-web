# Lineup

Use this workflow when the user asks for a starting XI, rotation plan, or formation advice.

1. Read the squad list and note each player's natural position and form.
2. Choose a formation that fits the squad (default 4-3-3).
3. Fill the XI from the back: keeper, back line, midfield, front line.
4. Give each pick a one-line rationale. Flag forced picks and rotation risks.
5. End with a compact `GK / DEF / MID / FWD` table and one substitution suggestion.

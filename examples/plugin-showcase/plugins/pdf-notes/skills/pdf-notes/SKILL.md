# PDF Notes

Use this when the user shares a PDF or asks for a reading summary.

1. Identify the document type, audience, and decision it supports.
2. Extract the three most important points, each with a page reference.
3. Separate decisions from open questions.
4. End with a short "what to do next" line.
5. Never invent page numbers; if unavailable, say so.
